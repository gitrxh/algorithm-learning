# 模板

[返回首页](../README.md) · [模板遗忘记录表](forgetting_log.md)

复制后填写，保留对本次学习有用的部分即可。模板用于统一笔记结构，也可逐步沉淀自己常用的解题套路和 PyTorch 张量处理思路。

| 模板 | 用途 | 复制到哪里 |
| --- | --- | --- |
| [LeetCode 笔记](leetcode_note.md) | 网页刷题后的思路、边界与复盘 | `leetcode_hot100/四位题号_英文题名.md` |
| [LLM 算法笔记](llm_note.md) | 公式、张量形状、PyTorch 操作、自测 | `llm_algorithms/对应模块/算法名.md` |
| [遗忘记录表](forgetting_log_template.md) | 后续新增学习部分时建立复习表 | `新部分/forgetting_log.md` |

## 维护方式

- 复制模板后替换标题、占位字段和链接，并将笔记加入所属部分 README。
- 可复用的算法套路后续按需新增为 Markdown，例如 `sliding_window.md`、`tensor_shapes.md`，同时在这里添加索引。
- 具体题目的遗忘点记在 LeetCode 表，具体 LLM 算法的遗忘点记在 LLM 表；只有可复用套路本身的卡点记入[模板遗忘表](forgetting_log.md)。
