## 新增一题

1. 在网页做题，记录是否独立完成、是否看提示、在哪里卡住。
2. 复制[题目模板](../templates/leetcode_note.md)，命名为 `四位题号_英文题名.md`，保存到本目录。
3. 添加索引行；优先记思路、边界与复杂度，网页提交的代码可选择性粘贴。
4. 若有遗忘，在[遗忘记录表](forgetting_log.md)中写下可自测的问题，例如“为什么要先查哈希表，再加入当前元素？”
