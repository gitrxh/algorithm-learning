## 题目

把数组中的零移到末尾，保持所有非零元素的相对顺序，并直接修改原数组。题目要求函数本身不返回结果。

## 我的思路

先在第一个零的后面找到非零数字，把它的位置记为 `j`。随后从左到右遍历数组：遇到零时，将它与 `j` 位置的非零数字交换；交换后，从 `j` 开始继续寻找下一处非零数字。若找不到可交换的非零数字，剩余位置已经都是零。

这里的 `j = len(nums)` 是哨兵值，表示目前没有找到零后面的非零数字。`j >= len(nums)` 时结束外层循环。

## 本次代码

```python
class Solution(object):
    def moveZeroes(self, nums: list[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        j = len(nums)
        for i in range(1, len(nums)):
            if nums[i] != 0 and nums[i - 1] == 0:
                j = i
                break

        for i in range(len(nums)):
            if j >= len(nums):
                break
            if nums[i] == 0:
                nums[i] = nums[j]
                nums[j] = 0
                for k in range(len(nums) - j):
                    if nums[j + k] != 0:
                        j = j + k
                        break
        return nums
```

代码保留了粘贴内容中的 `return nums`，方便之后对照。它确实直接修改了传入的列表；但题目接口写的是“不返回任何内容”，且函数标注为 `-> None`，因此正式提交时可以去掉最后的 `return nums`。

## 手推一遍

以 `[0, 1, 0, 2]` 为例：先找到 `j = 1`；把首位零与 `1` 交换后得到 `[1, 0, 0, 2]`，再向后找到 `j = 3`；下一次交换得到 `[1, 2, 0, 0]`。非零数字 `1、2` 的顺序没有变化。

## 复杂度与后续改进点

- 额外空间：`O(1)`，只使用了几个下标变量，并原地交换。
- 最坏时间：`O(n²)`。寻找下一处非零数字的内层循环，在后面全是零时会反复扫描同一段后缀。例如 `[0, 1, 0, 0, …]`，第一次交换后仍会对后缀中的多个零重复查找。
- 若以后需要降低时间开销，可思考怎样让寻找非零数字的位置**只向前移动、不重复扫过已经检查的区间**。本次先保留自己完成的写法。

## 本题收获

先定位零后面的非零数字，再交换和更新位置，是一种直接的原地修改思路。复习时检查三个条件：是否把所有零移到末尾、非零元素是否保持原有顺序、是否只修改传入列表。需要重复复习的具体卡点再记入[本部分遗忘表](forgetting_log.md)。
